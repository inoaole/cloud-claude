# Commit Log — 2026-07-01 · v0.3 (feature/v0.3.0/react-migration)

- `feat(v0.3): migrate PWA frontend to React + TS, fix iPhone safe-area`
  Replace the hand-written pwa/ HTML/CSS/JS with a Vite + React + TypeScript SPA in
  `frontend/`. Backend/hub logic unchanged; only what it serves changed.

  **Scaffold:** Vite + React 18 + TS, React Router v6 (tabs = routes), CSS Modules +
  `styles/tokens.css` (DESIGN.md vars — single source; adds the design-review tertiary
  `--t4` for 4.5:1 muted-text contrast + a Growth-only project palette / heat ramp).
  vite-plugin-pwa (Workbox generateSW) with a navigateFallback DENYLIST for
  `/auth /logout /api /pty /healthz` so the SW never turns an auth/API failure into a
  cached HTML shell; `clientsClaim`+`skipWaiting` supersede the old hand-rolled sw.js.
  Dev `server.proxy` routes /auth,/api,/pty,/healthz to the hub → same-origin cookies.

  **Safe-area fix (the iPhone 16 Pro bug):** `AppShell` is a `100dvh` grid
  (header / scrollable content / TabBar); the content row owns scroll and the TabBar sits
  in-grid with `padding-bottom: env(safe-area-inset-bottom)`, lifting the tabs ABOVE the
  iOS home indicator instead of the old fixed bar overlapping it.

  **Unlock:** custom keypad (no `<input>` → no iOS keyboard), all visual states from the
  design review — idle / entering / submitting (`→` pulse) / wrong-PIN (shake + clear) /
  lockout countdown / no-PIN / success fade. Auth state machine `checking|authed|unauthed
  |error`: a `checking` splash prevents a protected-UI flash; a global 401 handler in
  `lib/api.ts` drops any protected request back to the gate (ignores /auth, /auth/me).

  **Screens:** 5 tab stubs as honest-quiet placeholders (never a bare "No items"); Today =
  the calm unlocked state; Settings has Hub status + Lock (logout). Distinct inline-SVG tab
  glyphs; a shared `Cell` disclosure row + `Group` grouped-list.

  **Hub wiring:** `config.paths.pwaDir` → `frontend/dist` (overridable via `PWA_DIR` for an
  atomic deploy); static serving sets immutable cache on hashed `/assets`, no-cache on
  sw.js + index.html.

  **Tests:** Vitest — Unlock keypad/states (4) + api 401-gate & login mapping (8) = 12
  green. 1 Playwright smoke (unauth surface: unlock renders, keypad fills, routes stay
  gated on deep-link + refresh) green on the iPhone-15-Pro webkit profile.

  Verified locally: `npm run build` clean (tsc -b + vite), hub serves the SPA
  (deep-link /growth → shell, /auth/me 401 unauth). Old `pwa/` kept until the React build is
  deployed + smoke-tested on the real iPhone home-screen install, THEN deleted.
  Remaining for Exit: build → atomic deploy on the hub → iPhone 16 Pro safe-area screenshot.
